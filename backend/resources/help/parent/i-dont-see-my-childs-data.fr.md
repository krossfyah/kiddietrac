# Je ne vois pas les données de mon enfant

Si vous vous connectez et que votre enfant n’apparaît pas, ou que ses données semblent vides, voici ce qu’il faut vérifier.

## « Je ne vois pas du tout mon enfant »

Cause la plus fréquente : le directeur du centre vous a lié à la **famille**, mais l’**enfant** n’est pas encore inscrit dans la famille.

- Communiquez avec votre directeur
- Demandez-lui de confirmer que votre enfant est inscrit dans la même famille à laquelle vous êtes lié comme tuteur

## « Je vois mon enfant, mais aucun événement / aucune activité »

Les données du jour n’apparaissent que lorsque les éducateurs les consignent. Raisons possibles :

- **Il est tôt dans la journée** — attendez après l’arrivée du matin / les premiers événements
- **Les éducateurs utilisent le papier aujourd’hui** — la tablette est parfois en panne ou ils sont en retard
- **Votre enfant n’est pas encore arrivé** — tant qu’il n’est pas enregistré pour la journée, aucun événement n’est consigné
- **Vous regardez la mauvaise date** — vérifiez le sélecteur de date

## « Il manque des choses dans la chronologie que je sais être arrivées »

- **Actualisez complètement** l’application : tirez la page vers le bas (mobile) ou Ctrl+Maj+R (ordinateur)
- **Vérifiez si votre cache est périmé** — déconnectez-vous puis reconnectez-vous
- Si les données manquent toujours après cela, il est possible que l’éducateur ait oublié de les consigner. Demandez-lui directement dans Messages.

## « Mon enfant apparaît dans la mauvaise salle »

Cela arrive quand votre enfant est déplacé d’une salle à l’autre. Le directeur peut corriger la situation :

- Communiquez avec votre directeur
- Demandez-lui de mettre à jour l’affectation de salle

Le changement prend effet immédiatement.

## « Je vois l’enfant ou les renseignements d’une autre famille »

Cela ne devrait jamais arriver. Si c’est le cas, **faites une capture d’écran et écrivez immédiatement à votre directeur par courriel** — il pourrait y avoir un bogue de partage de données à corriger.

## « L’onglet Facturation indique “Aucune facture pour l’instant” »

C’est normal si votre directeur n’a pas encore généré les factures de ce mois, ou si votre enfant est inscrit depuis moins d’un mois complet.

Dès que votre directeur génère les factures, elles apparaîtront automatiquement.

## « J’ai perdu mon mot de passe »

Pour le moment, seul le directeur du centre peut réinitialiser votre mot de passe. Communiquez avec lui. La réinitialisation en libre-service arrive bientôt.

## Qui contacter selon le cas

| Problème | Qui contacter |
|---|---|
| Je ne vois pas mon enfant | Votre directeur |
| Il manque des événements dans la chronologie | Votre éducateur (Messages) |
| La facture semble erronée | Votre directeur |
| L’application est lente / ne fonctionne pas | Faites une capture d’écran et écrivez à support@kiddietrac.com |
| Je veux ajouter un autre tuteur | Votre directeur |
| Je veux modifier mes coordonnées | Votre directeur |

## Toujours bloqué?

Cliquez sur le bouton **Demander** en haut de n’importe quelle page d’Aide. L’assistant IA a accès à toute cette documentation et peut vous donner une réponse plus précise pour votre situation.

Ou écrivez à support@kiddietrac.com en indiquant :

- Votre nom et votre centre
- Ce que vous essayiez de faire
- Ce que vous avez vu à la place
- Une capture d’écran, si possible
