# Fichiers de votre prestataire

Le prestataire de votre enfant peut vous envoyer des documents à imprimer, des devoirs et des notes. Vous les trouverez dans **Fichiers** (📎 dans le menu ou sur votre écran d’accueil).

## Ouvrir un fichier

Les nouveaux fichiers sont marqués d’un point. Appuyez sur **Voir** pour ouvrir un PDF ou une image dans l’application, ou sur **Télécharger** pour l’enregistrer. Les autres types de fichiers (Word, Excel) se téléchargent et s’ouvrent dans leur propre application.

Vous recevrez une notification quand un nouveau fichier arrive, et habituellement un courriel aussi — le courriel indique seulement qu’un fichier vous attend; le fichier reste en sécurité dans KiddieTrac.

## Renvoyer quelque chose

1. Ouvrez **Fichiers** et appuyez sur **📤 Envoyer des fichiers**.
2. Déposez ou choisissez jusqu’à 10 fichiers (20 Mo chacun) : PDF, images, Word, Excel, PowerPoint ou texte.
3. Ajoutez une note si vous le souhaitez — par exemple « Devoirs pour lundi ».
4. Appuyez sur **Envoyer**. Le tout est transmis au prestataire de votre enfant.

Vous pouvez supprimer un fichier que vous avez envoyé depuis l’onglet **Envoyé**.
