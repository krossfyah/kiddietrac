# RH : configurer les types de congé

Les administrateurs d'agence configurent les congés sous **RH → Types de congé**. Ce sont les règles de votre agence : KiddieTrac n'applique aucune loi provinciale ou d'État sur l'emploi.

## Types de congé

**Ajouter un type de congé** demande un nom, une couleur, jours ou heures, payé ou non, s'il est visible par le personnel et s'il exige une approbation. Un type sans approbation est approuvé dès la demande.

**Charger l'exemple** ajoute Vacances, Jours de maladie, Jours personnels, Deuil et Congé non payé avec des montants d'exemple, marqués **Exemple**. Modifiez chaque valeur selon votre politique. Rien n'est appliqué automatiquement.

## Règles d'admissibilité

Chaque type a des règles : un montant par an, selon le type d'emploi et les années de service. La règle avec le plus d'années atteintes s'applique; une règle pour le type d'emploi l'emporte sur une règle pour tous.

## Accumulation

- **Une fois par an**, au début de l'année de congé.
- **À chaque période de paie** (12, 24, 26 ou 52 par an).
- **Selon les heures travaillées**, jusqu'au montant annuel.
- **Non suivi** : pas de solde.

## Report

À la fin de l'année, rien, tout ou jusqu'à une limite est reporté; les jours reportés peuvent expirer après quelques mois.

## Paramètres

L'année de congé commence à une date fixe ou à l'anniversaire d'embauche. Les demandes sous zéro sont refusées ou permises avec un avertissement. La règle des absences courtes répétées est un simple compte.

## Demandes antérieures

**Anciennes demandes classées comme** relie un type aux anciens types de demande. **Compter les demandes approuvées cette année** les retire des soldes, une fois. Les demandes ne changent jamais.
