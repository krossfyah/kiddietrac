# Provider map

A reference map of every provider (centre) in your agency, plotted by their
address. Find it under **Overview → Provider map** in the left menu.

![Provider map in the Overview menu](https://api.kiddietrac.com/help-img/provider-map.png)

## What you see

- A **list** of all your providers on the left — each with its address and a
  status (Located, or a note if the address is missing or couldn't be found).
- A **map** on the right with a pin for every located provider. Click a pin (or
  a provider in the list) to see its name, address, phone, and capacity.

## How locations are worked out

Pins are placed from each centre's **address** (Settings → Centres). The map
uses OpenStreetMap and looks up each address the first time you open the map,
then remembers it so the map loads instantly afterwards.

If a provider shows **"Could not locate this address"**, check and correct the
centre's street address, city, province, and postal code under
**Settings → Centres** — then reopen the map.

> Who can use this: **Agency admin** (sees all centres in the agency).
