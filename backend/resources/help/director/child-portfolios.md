# Child portfolios

A chronological view of every observation, photo, and milestone for a single child — useful for year-end summaries, parent meetings, and transitions to kindergarten. Open it from any child's record by hitting **View portfolio**.

## What's in the portfolio

- **Header**: child's name + photo + date of birth
- **Stat tiles**: total observations, milestones achieved, in-progress, emerging
- **Observation timeline**: every HDLH / ELECT / ELOF observation logged, newest first, with framework + domain + recorder visible per entry
- **Milestone records**: every milestone tagged for the child, with status

## Who can view

- The child's guardians
- Any staff active at the child's centre
- Agency admins + platform admins for any child in their scope

## What's not in it (yet)

PDF export is a v22p50+ item — for now the in-portal view is the canonical surface. You can print the page from the browser as a workaround.
