# Notes rapides

Un bloc-notes pour ce que vous devez retenir : écrivez une note en quelques secondes et gardez-la pour vous seul, ou partagez-la avec votre personnel.

## Où la trouver

Appuyez sur le bouton **📓** de la barre du haut pour ouvrir le bloc-notes, ou ouvrez **Notes** dans le menu latéral (sous Tâches) pour l'écran complet. Vous pouvez aussi ajouter la carte **Notes rapides** à votre tableau de bord : **+ Ajouter un widget → Notes rapides**.

[[open: #notes | Ouvrir Notes]]

## Écrire une note

1. Écrivez dans la zone et appuyez sur **Entrée** pour enregistrer. **Maj+Entrée** commence une nouvelle ligne.
2. Si la note a plus d'une ligne, la première devient son titre.
3. Choisissez **🔒 Moi seul** ou **👥 Agence** avant d'enregistrer, et une couleur si vous le souhaitez.

## Qui la voit

Les notes **Moi seul** sont privées : vous seul pouvez les voir, ni votre directeur, ni un administrateur, ni le soutien KiddieTrac. Les notes **Agence** sont pour le personnel de votre agence. Tout membre du personnel qui peut en voir une peut la modifier, et chaque changement est conservé. Une note partagée peut être pour toute l'agence ou pour un centre, et une note partagée reste partagée.

Les administrateurs voient toutes les notes de l'agence. Les directeurs voient les notes de toute l'agence et celles de leurs propres centres. Un directeur peut supprimer toute note partagée de ses centres; un administrateur, toute note partagée.

## Épingler, colorer, lier et rappeler

- **📌 Épingler** garde une note en haut.
- **🎨 Couleur** vous aide à trier vos notes d'un coup d'œil.
- **✏️ Modifier** permet de lier une note à un enfant, une famille ou un membre du personnel. Elle apparaît alors aussi sur la page de ce dossier, pour le personnel qui peut le voir. Une note partagée liée à un enfant ou à une famille appartient au centre de cet enfant.
- Ajoutez une date de **rappel** : la note apparaît ce jour-là dans votre calendrier et vos tâches, dans le panneau de droite. Le rappel d'une note privée n'est montré qu'à vous.

## Historique

Appuyez sur **🕘** sur une note partagée pour voir qui l'a créée, qui a changé quoi et quand. Les changements aux notes partagées sont aussi conservés dans le journal d'audit.

## Rechercher

Utilisez **Rechercher dans les notes** pour trouver une note par n'importe quel mot de son titre ou de son texte. **Mes notes** et **Notes de l'agence** passent de vos notes privées aux notes partagées.
