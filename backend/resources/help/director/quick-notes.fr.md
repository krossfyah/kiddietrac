# Notes rapides

Un bloc-notes pour ce que vous devez retenir : écrivez une note en quelques secondes et gardez-la pour vous, ou partagez-la avec votre personnel. Appuyez sur le bouton **📃** dans la barre du haut pour ouvrir le tiroir du bloc-notes, ou ouvrez **Notes** dans le menu latéral (sous Opérations) pour l’écran complet. Vous pouvez aussi ajouter la carte **Notes rapides** à votre tableau de bord : **+ Add widget → Quick notes**.

[[open: #notes | Ouvrir les notes]]

## Écrire une note

1. Ajoutez un titre dans **Title (optional)** si vous le voulez.
2. Écrivez la note dans la grande zone en dessous (**Écrivez une note rapide…**).
3. Choisissez **🔒 Moi seulement** ou **👥 Agence**. Pour une note d’agence dans une agence à plusieurs centres, choisissez **À l’échelle de l’organisme** ou un centre.
4. Choisissez une pastille de couleur si vous le voulez, et ajoutez des images avec **🖼 Add picture** (voir plus bas).
5. Appuyez sur **Enregistrer**. Sur un ordinateur, **Entrée** enregistre aussi (**Maj+Entrée** commence une nouvelle ligne). Sur un téléphone ou une tablette, Entrée commence une nouvelle ligne et le bouton **Enregistrer** enregistre.

La liste montre seulement le titre de chaque note, sur une ligne. Une note sans titre est listée par sa première ligne. Touchez un titre pour ouvrir la note au complet.

## Images

Ajoutez jusqu’à 5 images à une note, comme une capture d’écran ou la photo d’un avis :

- Sur un ordinateur, collez une capture d’écran dans la note (**Ctrl+V**, ou **Cmd+V** sur un Mac), glissez une image dessus, ou appuyez sur **🖼 Add picture**.
- Sur un téléphone, **🖼 Add picture** ouvre l’appareil photo ou vos photos.
- Vous pouvez ajouter des images en écrivant une nouvelle note ou dans **Modifier la note**. Touchez une image pour la voir en plein format; appuyez sur **✕** sur l’image pour la retirer.

Les images sont réduites sur votre appareil et leurs données de position sont retirées avant l’envoi. Une image est vue exactement par les personnes qui voient sa note, et elle est supprimée avec elle. Dans la liste, **🖼 3** signifie que la note contient 3 images. Chaque image peut faire jusqu’à 10 Mo (PNG, JPG, WebP ou GIF).

## Épingler, colorer, lier et programmer un rappel

1. Appuyez sur **📌** (**Épingler en haut**) pour garder une note en haut; appuyez sur **📍** pour la désépingler.
2. Appuyez sur **🎨** (**Couleur**) pour colorer une note et repérer vos notes d’un coup d’œil.
3. Appuyez sur **✏️** (**Modifier**) pour ouvrir **Modifier la note**. Vous pouvez y changer le texte, lier la note à un enfant, une famille ou un membre du personnel sous **Lié à**, et choisir une date de **Rappel**. Appuyez sur **Enregistrer**.

Une note liée s’affiche aussi sur la page de ce dossier, pour le personnel qui peut voir ce dossier. Une note partagée liée à un enfant ou à une famille appartient au centre de l’enfant. Le jour du rappel, la note s’affiche dans votre calendrier et dans les tâches du panneau de droite. Le rappel d’une note privée n’est jamais montré qu’à vous.

## Chercher et changer de liste

1. Utilisez **🔒 Mes notes** et **👥 Notes de l'agence** pour passer de vos notes privées à vos notes partagées.
2. Tapez dans **Rechercher dans les notes** pour trouver une note par n’importe quel mot de son titre ou de son texte.
3. Appuyez sur **🕘** (**Historique**) sur une note partagée pour voir qui l’a créée, qui a changé quoi et quand.

## Qui peut faire quoi

- Les notes **Moi seulement** sont privées : vous seul pouvez les voir — ni votre directeur, ni un administrateur, ni le soutien KiddieTrac.
- Les notes **Agence** sont destinées au personnel de votre agence. Tout membre du personnel qui peut en voir une peut la modifier, et chaque changement est conservé. Une note partagée reste partagée.
- Les **administrateurs de l’agence** voient toutes les notes de l’agence et peuvent supprimer n’importe quelle note partagée.
- Les **directeurs de centre** voient les notes de toute l’agence et celles de leurs propres centres, et peuvent supprimer n’importe quelle note partagée de leurs centres.
- Les **éducateurs et les visiteurs à domicile** voient les notes de toute l’agence et celles de leurs centres, et peuvent écrire les leurs.
- Les parents ne voient jamais les notes.

## FAQ et dépannage

??? Je ne peux pas rendre une note partagée privée de nouveau. | Une note partagée reste partagée, car d’autres membres du personnel peuvent déjà s’y fier. Écrivez plutôt une nouvelle note Moi seulement.
??? Le message « Pick an agency to see and share agency notes. » s’affiche. | Vous avez plus d’une agence. Choisissez d’abord l’agence dans la barre du haut.
??? Le message « Write something first. » s’affiche. | Une note doit contenir du texte avant de pouvoir être enregistrée.
??? Une image ne s’ajoute pas. | Seules les images PNG, JPG, WebP ou GIF d’au plus 10 Mo peuvent être ajoutées, jusqu’à 5 par note. Une photo HEIC de téléphone ne peut pas être lue ici : partagez-la en JPG, ou faites-en une capture d’écran.
??? J’ai supprimé une note par erreur. | Une note supprimée disparaît de la liste pour de bon. Pour une note partagée, son historique reste au journal d’audit.
