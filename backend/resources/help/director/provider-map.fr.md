# Carte des prestataires

Une carte de référence de chaque prestataire (centre) de votre agence, placé selon son
adresse. Vous la trouverez sous **Aperçu → Carte des prestataires** dans le menu de gauche.

![Carte des prestataires dans le menu Aperçu](https://api.kiddietrac.com/help-img/provider-map.png)

## Ce que vous voyez

- Une **liste** de tous vos prestataires à gauche, chacun avec son adresse et un
  statut (Localisé, ou une remarque si l’adresse est manquante ou introuvable).
- Une **carte** à droite avec une épingle pour chaque prestataire localisé. Cliquez sur une épingle (ou
  sur un prestataire dans la liste) pour voir son nom, son adresse, son téléphone et sa capacité.

## Comment les emplacements sont déterminés

Les épingles sont placées à partir de l’**adresse** de chaque centre (Paramètres → Centres). La carte
utilise OpenStreetMap et recherche chaque adresse la première fois que vous ouvrez la carte,
puis la mémorise pour que la carte s’affiche instantanément par la suite.

Si un prestataire affiche **« Adresse introuvable »**, vérifiez et corrigez
l’adresse municipale, la ville, la province et le code postal du centre sous
**Paramètres → Centres**, puis rouvrez la carte.

> Qui peut l’utiliser : **Administrateur d’agence** (voit tous les centres de l’agence).
