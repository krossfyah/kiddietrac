# Étapes de développement

Une liste de vérification structurée d’étapes alignées sur HDLH, répartie en quatre groupes d’âge (nourrisson, bambin, préscolaire, maternelle) et quatre domaines (Appartenance, Bien-être, Engagement, Expression). S’ouvre depuis le dossier de n’importe quel enfant.

## Marquer une étape

Chaque étape comporte trois boutons en forme de pastille :

- **Émergent** (gris) — l’enfant commence tout juste à montrer des signes de cette habileté
- **En cours** (ambre) — l’habileté apparaît, mais de façon irrégulière
- **Acquis** (vert) — l’habileté est démontrée de façon constante

Touchez une pastille pour mettre à jour. Les tuiles de statistiques du portfolio se mettent à jour immédiatement.

## Catalogue et étapes personnalisées

Le catalogue intégré couvre environ 28 étapes. L’ajout d’étapes personnalisées, l’importation du continuum HDLH complet ou l’alignement sur ELECT/ELOF figurent dans la feuille de route v22p51.

## Visibilité pour les parents

Les tuteurs voient la même liste pour leurs propres enfants et peuvent suivre les progrès dans le temps. Les changements de statut d’une étape apparaissent dans le fil **Aujourd’hui** lorsque le personnel les met à jour.
