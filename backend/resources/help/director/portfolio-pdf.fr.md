# Exportation du portfolio en PDF

Un PDF imprimable et partageable de tout ce que contient le portfolio d’un enfant : jalons, observations et activités quotidiennes récentes.

## Comment le télécharger

1. Ouvrez l’écran **portfolio** de l’enfant (Enfants → cliquez sur un enfant → bouton **Portfolio**).
2. Cliquez sur **⤓ Télécharger le PDF** dans la barre d’outils.
3. Un PDF de plusieurs pages est téléchargé : page couverture, jalons regroupés par statut, toutes les observations en ordre chronologique inverse, puis les 60 dernières entrées du journal quotidien.

## Quand l’utiliser

- Souvenir de fin d’année pour la famille
- Dossier de transition lorsqu’un enfant passe à l’école
- Dossier de conformité pour une inspection du centre
- Imprimer une copie pour une rencontre parents-éducateurs

Le PDF respecte votre image de marque personnalisée : logo de l’agence sur la couverture, votre courriel de soutien en pied de page.
