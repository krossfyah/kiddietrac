# Announcements

Post agency-wide or centre-wide notices that families and staff see in the
portal, by email, and optionally by SMS.

## Posting an announcement

1. Sidebar → **Announcements** → **+ New announcement**. The window pops up over a
   dimmed background.
2. Enter a **Title**.
3. Write the body in the **rich-text editor** — use the toolbar for **bold**,
   *italic*, underline, bulleted/numbered lists, and links. Formatting is kept in
   the emailed copy.
4. Choose the **audience** (all families, a centre, staff, etc.).
5. Optionally tick **Also send as SMS** to text the announcement to recipients
   with a mobile number on file. (SMS strips formatting and sends as plain text,
   so keep it short. SMS must be enabled under **Settings → Billing → Settings**.)
6. Click **Publish**.

## How recipients get it

- **In-app** — a notification plus the announcement in their feed.
- **Email** — the formatted HTML version, sent from your agency's address when
  configured (white-label).
- **SMS** — a plain-text version, only if you ticked **Also send as SMS**.

> Who can use this: **Centre director** (their centre), **Agency admin** (whole
> agency).
