# Custom reports

Build a saved report with picked columns + filters + sort order. Run it any time. Share with your agency.

## Creating a report

1. Sidebar → **Reports**.
2. Tap **+ New report**.
3. Enter name + pick a data source:
   - Users · Families · Children · Invoices · Payments
   - Observations · Background checks · Time punches · Tour bookings
4. Optionally specify columns (defaults to all), filters, sort column + direction.
5. Tick **Share with my agency** if other admins should see it.
6. Tick **Add to favourites** for quick-access from the Favourites panel.
7. Save.

## Running a report

- Open the Reports list. Two panels at the top: **⭐ Favourites** and **🕘 Recently run**.
- Tap **Run** on any saved report.
- A modal opens with the matching rows + a downloadable XLSX.

## Editing a report

Open the report from the All-saved-reports table → modify any field. Changes save on the next Run.

## Sharing

Reports you tick "Share" appear in other admins' Reports list under "Shared". Useful for monthly board reports the team co-owns.

## When to use vs. quick XLSX exports

- **Built-in XLSX buttons** (Users / Families / Audit log / etc.) — quick one-off dumps with default columns.
- **Custom reports** — when you want the same filtered view repeatedly (e.g. "Children turning 4 this month who haven't done their MMR booster").
