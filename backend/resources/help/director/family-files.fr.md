# Fichiers partagés avec les familles

**Fichiers** (📎 dans le menu latéral) est l’endroit où le personnel et les familles s’échangent des documents à imprimer,
des devoirs, des notes et des documents signés. Les directeurs et les administrateurs de l’agence peuvent aussi envoyer des fichiers, et
voir tous les fichiers échangés avec les familles dont ils s’occupent.

[[open: #files | Ouvrir les fichiers]]

Sur un téléphone, **Fichiers** se trouve aussi dans vos tuiles d’**Accès rapide** sur l’écran d’accueil.

## Les onglets

- **Reçus** : les fichiers envoyés par les familles. Les nouveaux ont un point, et l’onglet indique combien sont nouveaux, par exemple **Reçus (3 nouveaux)**.
- **Envoyés** : les fichiers que vous avez envoyés vous-même.
- **Tous les fichiers** : tous les fichiers échangés avec les familles que vous pouvez voir, dans les deux sens, peu importe l’expéditeur. La colonne **De → À** indique qui l’a envoyé et à quelle famille. Les administrateurs de l’agence voient toute l’agence. Les directeurs voient les familles de leurs propres centres.

> **Astuce :** Utilisez **Tous les fichiers** pour vérifier ce qu’un éducateur a envoyé à une famille, ou ce qu’une famille a renvoyé, sans avoir à poser la question.

Les éducateurs et les visiteurs à domicile ont le même onglet, appelé **Tous avec mes familles**. Il montre
seulement les familles des enfants dont ils ont la charge.

## Envoyer un fichier

1. Ouvrez **Fichiers** et appuyez sur **📤 Envoyer des fichiers**.
2. Déposez ou choisissez jusqu’à 10 fichiers, 20 Mo chacun : PDF, images, Word, Excel, PowerPoint ou texte.
3. Ajoutez un titre et une note si vous le souhaitez.
4. Cochez une ou plusieurs familles, puis appuyez sur **Envoyer**.

## Qui est avisé

La personne à qui un fichier est destiné reçoit toujours une notification dans l’application. Par défaut, elle reçoit aussi un
courriel, dans **les deux** sens :

- Les **parents** reçoivent un courriel lorsqu’un fichier leur est envoyé.
- Le **personnel** qui s’occupe de la famille reçoit un courriel lorsqu’une famille envoie un fichier.

Le courriel indique seulement qu’un fichier est en attente. Le fichier n’est jamais joint; il reste dans KiddieTrac.

## Désactiver les courriels (administrateurs de l’agence)

1. Menu latéral → **Paramètres** → **Notifications de l’agence**.
2. Ouvrez l’onglet **📎 Fichiers partagés**.
3. Activez ou désactivez **Envoyer un courriel aux parents pour les nouveaux fichiers** ou **Envoyer un courriel au personnel lorsqu’une famille envoie un fichier**.
4. Appuyez sur **Enregistrer**.

Lorsqu’un courriel est désactivé, les gens voient tout de même la notification dans l’application.

??? Puis-je supprimer un fichier envoyé par un éducateur? | Non. Seule la personne qui a envoyé un fichier peut le supprimer. La suppression le retire pour tous ceux à qui il a été envoyé.
??? Est-ce la même chose que le dépôt de fichiers? | Non. Le dépôt de fichiers est une étagère de documents de vente réservée aux administrateurs de la plateforme. Fichiers sert à partager avec les familles.
