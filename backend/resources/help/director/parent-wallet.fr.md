# Portefeuille du parent

Enregistrez jusqu’à **six modes de paiement** par famille — cartes de crédit, cartes de débit et DPA canadien (compte bancaire) — et choisissez-en un comme mode par défaut pour le prélèvement automatique.

## Ajouter un mode de paiement

1. Barre latérale → **Portefeuille**.
2. Touchez **+ Ajouter une carte de crédit/débit** ou **+ Ajouter un compte bancaire (DPA)**.
3. Saisissez les renseignements de la carte ou du compte bancaire dans le formulaire sécurisé par Stripe.
4. Vous pouvez aussi nommer le mode de paiement (p. ex. « Ma carte de tous les jours ») pour les distinguer plus tard.

Les renseignements de carte ne transitent jamais par nos serveurs : ils vont directement à Stripe.

## Définir le mode par défaut

Le mode par défaut est celui qui est débité automatiquement lorsqu’une facture arrive à échéance. Le premier mode ajouté devient automatiquement le mode par défaut. Touchez **Définir par défaut** sur un autre mode pour changer.

## Supprimer un mode de paiement

Touchez **Supprimer** sur n’importe quel mode enregistré. S’il s’agissait du mode par défaut, le mode ajouté ensuite est promu automatiquement. Supprimer votre seul mode de paiement désactive le prélèvement automatique.

## Limites

- Maximum de 6 modes par famille (conforme à la norme de Procare)
- Ajouter une carte OU un compte bancaire ne vous débite pas à l’avance : cela enregistre seulement l’instrument de paiement pour un usage futur.
