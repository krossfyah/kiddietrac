# Closures

Holidays, PD days, emergency closures. Pause billing on closures (or not), and notify families automatically.

## Adding a closure (admin / director)

1. Sidebar → **Closures**.
2. Tap **+ New closure**.
3. Pick the centre + start date (+ end date for multi-day).
4. Pick type: Holiday / PD day / Emergency / Renovation / Other.
5. Add a reason (e.g. "Family Day").
6. Tick **Pause billing** if billing should not run on these days (default on).
7. Save.

## What happens automatically

- All families at that centre get an in-app + email notification.
- Closure shows on the staff schedule + parent Today screen.
- If billing-paused, the daily tuition cron skips these dates when generating invoices.

## Removing

Open the closure row and tap **Remove**. Notifications already sent are not retracted.

## Common closures to pre-add for Ontario

New Year's Day · Family Day · Good Friday · Easter Monday · Victoria Day · Canada Day · Civic Holiday · Labour Day · Thanksgiving · Remembrance Day · Christmas Eve · Christmas Day · Boxing Day · New Year's Eve.

Plus your centre's PD days + staff training days.
