# Requesting files

**Engagement → Forms Manager → Request files.** Ask a parent or a staff member for
documents they already have: an immunization card, both sides of an ID, a tax slip. They
upload from a link with no password, and everything lands on their own record.

A form package sends out a document for someone to fill in. A file request works the
other way round: it asks for something they hold. Each is tracked line by line, so
"have they sent everything?" has an answer without reading back through an email thread.

[[show: #forms-manager @ Request files > + Request files | Show me the Request files button]]

## Making a request

1. Press **+ Request files**.
2. **Ask**: choose a person, or type their address. The address must belong to someone
   with an account at your agency.
3. Set a **Priority** (Low, Normal, High, Urgent) and, if it matters, a **Needed by**
   date.
4. Add a **Note** if they need to know where to find something or why you need it.
5. Under **What do you need?**, add one line per document. Each line has a description,
   a kind (**Any file**, **PDF**, **Photo/scan**, **Word doc**) and how many files you
   expect, up to 20. Use **+ Add another** for more lines.
6. Leave **Email them now** ticked and press **Send request**.

They get one email with a link, and a button for each thing you asked for. The link
works for 21 days and accepts only the documents listed. Each file can be up to 15 MB.

## What happens when files arrive

- Every file is filed on the person's record, so it shows in their **Documents** and on
  their user record. There is no separate place to look.
- When the last item arrives, the request is marked complete. The person who asked gets
  an email saying so, and the sender gets a receipt.

## Following up

The table shows each request with how much has come back (**2 of 3**, or **✓ All 3**),
its priority and its due date. A due date that has passed is marked **overdue** in red.

The **⋮** menu on each request:

- **View files**: what was asked for, what has arrived, and **View** or **Download** for
  each file.
- **Open upload link** opens the same link they were emailed and copies it to your
  clipboard. Use it when a family says the email never came, or when they are standing
  at the desk with the documents on their phone. The old email keeps working. Fetching
  the link is recorded in the audit log.
- **Download n file(s)** saves everything they sent, one file after another.
- **Send reminder** emails them about the items still outstanding.
- **Delete request** removes the request itself. Any files already sent stay on their
  record.

> **Important:** The upload link is a real key to that person's upload page. Only share it with the person it was made for.

## Who can do this

Agency admins and directors at your agency. Files are opened through the portal, never
from a public address, because these are ID documents and health records.
