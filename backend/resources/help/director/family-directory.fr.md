# Répertoire des familles

Entrez en contact avec les autres familles de votre centre. Strictement sur adhésion volontaire.

## Adhérer

1. Menu latéral → **Répertoire des familles**.
2. Choisissez ce que vous partagez :
   - **Partager mon courriel** — les autres familles peuvent vous écrire
   - **Partager mon téléphone** — les autres familles peuvent vous appeler ou vous texter
   - **Partager mon adresse (ville seulement)** — jamais votre adresse civique, seulement votre ville
   - **Afficher le prénom de mes enfants** — aide les familles à se reconnaître
3. Touchez **Enregistrer les préférences**.

Vous pouvez désactiver n’importe lequel de ces choix en tout temps — les changements s’appliquent instantanément.

## Parcourir le répertoire

Le même écran défile vers le bas pour afficher toutes les autres familles de votre centre ayant adhéré. Les fiches montrent ce que chaque famille a choisi de partager.

## Ce qui n’est JAMAIS partagé

- L’adresse civique (la ville seulement, si vous adhérez)
- Le téléphone si vous n’avez pas adhéré
- Le courriel si vous n’avez pas adhéré
- Les noms de famille des enfants
- La date de naissance des enfants
- Toute information de facturation ou de paiement
- Tout ce que vous n’avez pas explicitement activé

## Cas d’usage

- Coordination du covoiturage
- Organisation de jeux entre enfants
- Réunions de parents de la classe
- Événements communautaires

## Rappel sur la confidentialité

Les autres familles voient ce que vous avez partagé, mais pas ce que vous n’avez pas partagé. L’adhésion se fait par famille, et non par autre famille. Il n’existe pas de partage précis du type « avec cette famille mais pas celle-là » : vous partagez avec tout le monde dans votre centre, ou avec personne.
