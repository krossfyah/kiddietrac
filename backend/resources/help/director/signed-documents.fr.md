# Documents signés — le registre des signatures électroniques

**Engagement → Documents signés** est le registre des ententes que des personnes ont
acceptées avec une signature électronique dans le portail : la politique de confidentialité
et l’entente de non-divulgation, les accusés de lecture du guide, les contrats d’inscription,
le consentement pour les photos, les autorisations médicales et les autorisations de sortie.
Ouvrez-le pour prouver qui a accepté quoi, et quand, ou pour remettre une copie à quelqu’un.

[[open: #signed-docs | Ouvrir Documents signés]]

> ℹ️ Les formulaires PDF envoyés depuis le **Gestionnaire de formulaires** sont dans son onglet **✅ Terminé**, et les PDF des **Documents électroniques** sous **Voir les signatures** sur chaque document. Cet écran contient les ententes intégrées.

## Trouver un document signé

1. Ouvrez **Documents signés**. Le tableau sous **Signé et au dossier** liste chaque signature des personnes de votre agence.
2. Tapez un nom ou un document dans la boîte de recherche au-dessus du tableau pour réduire la liste.
3. Cliquez sur un en-tête de colonne, **Document**, **Signé par** ou **Signé (heure de l’agence)**, pour trier.
4. Utilisez les boutons de page sous le tableau quand il y a plus de 25 lignes.

## Ouvrir ou enregistrer une copie

1. Trouvez la ligne.
2. Appuyez sur son bouton **⋮**.
3. Choisissez **Voir le document** pour le lire à l’écran, avec la signature et son estampille.
4. Choisissez **Télécharger** pour enregistrer le fichier. Son nom contient le document, le signataire et la date, pour un classement facile. **Télécharger** n’apparaît que si un fichier signé est conservé pour cette ligne.

## Lire une ligne

| Colonne | Signification |
|---|---|
| **Document** | Ce qui a été accepté, par exemple **Politique de confidentialité et entente de non-divulgation** ou **Consentement pour les photos**. « **— declined** » signifie que la personne l’a refusé, et le refus est aussi enregistré. |
| **Signé par** | La personne qui a signé. |
| **Signé (heure de l’agence)** | La date et l’heure, dans le fuseau horaire de votre agence. |

L’estampille sur le document ajoute l’adresse IP et l’emplacement approximatif d’où il a été
signé (ville, province ou État, pays). Personne ne tape ces renseignements : le serveur les
enregistre au moment de la signature.

## Qui peut faire quoi

| Rôle | Ce qu’il voit |
|---|---|
| Administrateur de l’agence | Chaque signature des personnes de l’agence où il travaille. |
| Administrateur de la plateforme | La même chose, pour l’agence choisie en haut. |
| Parent | Ses propres documents signés, à l’écran **Mes documents**. |
| Direction de service de garde, éducatrice ou éducateur | Aucun accès à cet écran. |

Rien sur cet écran ne peut être modifié ni supprimé. C’est un registre, pas une liste de tâches.

## FAQ et quand quelque chose ne va pas

??? La liste dit « No signed documents yet. » | Personne dans cette agence n’a encore signé une des ententes intégrées, ou vous travaillez dans une autre agence. Vérifiez le choix d’agence en haut.
??? Le formulaire d’un parent n’est pas ici. | Vérifiez de quel type de formulaire il s’agit. Un formulaire PDF du Gestionnaire de formulaires est dans son onglet Terminé; un document électronique est sous Voir les signatures sur sa carte.
??? Il n’y a pas de Télécharger pour une ligne. | Aucun fichier n’est conservé pour cette signature. Voir le document montre quand même l’enregistrement complet.
??? Puis-je supprimer une signature ici? | Non. Pour retirer une signature sur un formulaire du Gestionnaire de formulaires, utilisez ⋮ > Delete this sign-off dans son onglet Terminé.
??? Les heures correspondent-elles à ce que le parent a vu? | Les heures sont affichées dans le fuseau horaire de l’agence, comme partout ailleurs dans le portail.
