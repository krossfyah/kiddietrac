# Journaux de soins quotidiens

Un suivi en un clic pour ce que tous les parents demandent : couches, siestes, repas, biberons. Vous le trouverez dans la barre latérale sous **Opérations → Journal quotidien**.

## Ce que vous pouvez consigner

Huit types, chacun avec un bouton à toucher une fois :

| Type | À utiliser pour |
|---|---|
| 🧷 Couche | humide, selles, les deux |
| 🚽 Toilettes | visites aux toilettes pour les plus grands |
| 😴 Sieste | début du sommeil (consigner à nouveau au réveil) |
| 🍽️ Repas | déjeuner, dîner, souper |
| 🍎 Collation | collation du matin / de l’après-midi |
| 🍼 Biberon | avec la quantité en oz |
| ☀️ Écran solaire | pour le jeu à l’extérieur |
| 🙂 Humeur | heureux / grincheux / malade |

## Comment en consigner une

1. Choisissez l’enfant dans la liste déroulante en haut.
2. Touchez l’un des huit boutons de type.
3. Ajoutez un détail facultatif (p. ex. « humide seulement », « a mangé 3/4 du dîner ») et des notes.
4. Pour les biberons, saisissez la quantité en oz.
5. Cliquez sur **Consigner**.

L’entrée apparaît immédiatement dans le fil **Journal du jour** ci-dessous et met à jour le portail du parent en temps réel.

## Consigner pour toute la salle à la fois

L’écran solaire avant de sortir, ou la collation de l’après-midi, est une seule action concernant toute la salle,
et non dix actions identiques. Choisissez **Tous les enfants** en haut de la liste des enfants au lieu d’un
seul enfant, et l’entrée est consignée pour **tous les enfants actuellement présents**.

Disponible pour : **jeu à l’extérieur, collation, repas, biberon, écran solaire, humeur et sieste**.

**Couche et toilettes sont volontairement exclues.** Elles décrivent le corps d’un seul enfant, et les
consigner pour toute une salle enregistrerait des choses qui ne se sont pas produites.

Si personne n’est présent, on vous le signale et rien n’est consigné : une entrée pour toute la salle dans une salle vide est une erreur de manipulation, pas une intention.

## Ce que voient les parents

Le parent de chaque enfant reçoit une vue récapitulative de toutes les entrées de la journée, avec l’heure et le nom de l’éducateur. Les parents peuvent remonter 7 jours par défaut.
