# Rapports personnalisés

Créez un rapport enregistré avec les colonnes, les filtres et l’ordre de tri de votre choix. Exécutez-le quand vous voulez. Partagez-le avec votre agence.

## Créer un rapport

1. Barre latérale → **Rapports**.
2. Touchez **+ Nouveau rapport**.
3. Saisissez un nom et choisissez une source de données :
   - Utilisateurs · Familles · Enfants · Factures · Paiements
   - Observations · Vérifications d’antécédents · Pointages · Réservations de visites
4. Au besoin, précisez les colonnes (toutes par défaut), les filtres, la colonne de tri et le sens.
5. Cochez **Partager avec mon agence** si d’autres administrateurs doivent le voir.
6. Cochez **Ajouter aux favoris** pour y accéder rapidement depuis le panneau Favoris.
7. Enregistrez.

## Exécuter un rapport

- Ouvrez la liste des rapports. Deux panneaux en haut : **⭐ Favoris** et **🕘 Exécutés récemment**.
- Touchez **Exécuter** sur n’importe quel rapport enregistré.
- Une fenêtre s’ouvre avec les lignes correspondantes et un fichier XLSX téléchargeable.

## Modifier un rapport

Ouvrez le rapport depuis le tableau Tous les rapports enregistrés → modifiez n’importe quel champ. Les changements sont enregistrés à la prochaine exécution.

## Partage

Les rapports que vous cochez « Partager » apparaissent dans la liste des rapports des autres administrateurs sous « Partagés ». Utile pour les rapports mensuels du conseil que l’équipe gère en commun.

## Quand l’utiliser plutôt que les exportations XLSX rapides

- **Boutons XLSX intégrés** (Utilisateurs / Familles / Journal d’audit / etc.) — exportations ponctuelles rapides avec les colonnes par défaut.
- **Rapports personnalisés** — quand vous voulez la même vue filtrée de façon répétée (p. ex. « Enfants qui auront 4 ans ce mois-ci et qui n’ont pas reçu leur rappel ROR »).
