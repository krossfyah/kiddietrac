# Conferences

Teachers/directors publish available time slots; parents self-book one slot per child.

## Staff: publishing slots

1. Sidebar → **Conferences**.
2. Tap **+ Create slots**.
3. Pick centre + date + start/end time + duration (default 20 min).
4. The system generates one slot per duration window between start and end.
5. Optionally assign a teacher (or leave blank for any-available).
6. Save.

## Parent: booking

1. Sidebar → **Conferences**.
2. See all open slots at your centre.
3. Tap **Book** on a slot.
4. Pick which child the conference is about.
5. Done — the teacher gets a notification with the chosen time.

## Cancelling

- Either side can cancel a booking. Slot returns to open state.
- 24-hour cancellation policy is enforced by your centre, not the system.

## Reminders

Bookings appear on the family's Today screen 24 hours before the conference. Email reminders fire 1 day prior and 1 hour prior (if enabled in agency settings).

## Best practice

Cluster slots into 2-3 evening blocks per term so families can pick a time that works. Set conferences a month before term-end so observation discussion is fresh.
