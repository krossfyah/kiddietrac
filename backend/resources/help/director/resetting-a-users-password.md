# Resetting a user's password

If a parent or staff member is locked out (forgot password, never set one), you can reset their password manually.

## Right now: contact support

Self-service password reset is coming soon. Until then:

1. Email support@kiddietrac.com with the user's email address
2. Mention which centre they belong to
3. We'll reset their password and email you the new temporary password
4. You forward it to the user

Typical turnaround: same business day.

## What's coming

In a future update:

- Forgot password link on the login page
- User receives a password reset email
- They click the link, set a new password
- No director involvement needed

For now, the manual process keeps your customer secure since we can verify the request comes through you.

## What I tell users

When a user says "I can't log in":

1. First check: are they at **https://app.kiddietrac.com** (not your old iLearn URL or anywhere else)?
2. Are they using the email address that received the welcome invite?
3. Are they using the password from the welcome email, or one they set themselves?
4. Have they hard-refreshed (Ctrl+Shift+R)?

If all of that is true and they still can't log in, request a password reset for them.
