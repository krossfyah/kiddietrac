# Daily care logs

Quick-tap tracking for the things every parent asks about: diapers, naps, meals, bottles. Find it in the sidebar under **Operations → Daily log**.

## What you can log

Eight types, each a one-tap button:

| Type | Use it for |
|---|---|
| 🧷 Diaper | wet, BM, both |
| 🚽 Bathroom | toilet visits for older children |
| 😴 Nap | sleep start (record again at wake) |
| 🍽️ Meal | breakfast, lunch, supper |
| 🍎 Snack | morning / afternoon snack |
| 🍼 Bottle | with amount in oz |
| ☀️ Sunscreen | for outdoor play |
| 🙂 Mood | happy / fussy / sick |

## How to log one

1. Pick the child from the dropdown at the top.
2. Tap one of the eight type buttons.
3. Add an optional detail (e.g. "wet only", "ate 3/4 of lunch") and notes.
4. For bottles, enter the oz amount.
5. Click **Log it**.

The entry appears immediately in the **Today's log** feed below and updates the parent's portal in real time.

## What parents see

Each child's parent gets a rolled-up view of every entry from the day, with timestamps and the educator's name. Parents can scroll back 7 days by default.
