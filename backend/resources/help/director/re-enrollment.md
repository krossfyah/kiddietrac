# Re-enrollment campaigns

Confirm next term's enrolment with a one-tap parent action.

## Launching a campaign (admin)

1. Sidebar → **Re-enrollment**.
2. Tap **+ Launch campaign**.
3. Enter: campaign name (e.g. "Fall 2026"), target term, deadline (when responses are due).
4. Optionally restrict to one centre, or send agency-wide.
5. Launch.

The system invites every currently-enrolled child in the scope. Each family gets a notification + email.

## Parent response

1. Notification → opens the campaign screen.
2. For each child, tap **Yes / No / Unsure**.
3. Optional comment.
4. Submit.

## Tracking

The campaign list shows for each campaign:
- Total invited
- Total responded
- Total renewed (responded Yes)
- Status (planning / sent / closed)

## When to launch

- 60-90 days before term start
- After tuition increases are scheduled (so parents see new rates before committing)
- After CWELCC paperwork is renewed (so subsidy is locked in)

## Following up

The drip-campaign system (separate feature) can auto-send a follow-up email N days after the launch if the family hasn't responded.

## Closing a campaign

Manually mark a campaign closed once the deadline passes. Unresponded families go onto the staff manual-followup list.
