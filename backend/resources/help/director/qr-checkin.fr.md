# One-Tap (enregistrement par code QR)

**One-Tap** est le système d’arrivée et de départ sans contact par code QR de KiddieTrac. Imprimez une affiche One-Tap
pour la porte d’un centre : les familles la scannent avec l’appareil photo de leur téléphone pour enregistrer l’arrivée ou le départ
des enfants, sans tablette.

## Activation

1. Barre latérale → **Paramètres → Centres** (ou *Gérer ce centre* depuis l’Aperçu de l’agence).
2. Ouvrez un centre et repérez **Mode borne**.
3. Cochez **Activer la borne pour ce centre**. Une URL de borne et une carte
   **One-Tap (enregistrement par code QR)** apparaissent.

## Impression de l’affiche

1. Dans la carte One-Tap, cliquez sur **🖨️ Imprimer l’affiche One-Tap**.
2. Une affiche prête à imprimer s’ouvre (nom du centre, code QR One-Tap et les 3 étapes
   que suivent les familles). Imprimez-la et affichez-la à votre entrée.

Le code QR One-Tap est généré **dans votre navigateur** : le lien de la borne n’est jamais envoyé à
un tiers. Si vous renouvelez le jeton de la borne, réimprimez l’affiche.

## Comment les familles l’utilisent

1. Scannez le code avec l’appareil photo du téléphone.
2. Touchez le nom de l’enfant.
3. Entrez le NIP de la borne de 4 à 6 chiffres pour enregistrer l’arrivée ou le départ. (Définissez des NIP par tuteur depuis
   la fiche de la famille.)

> Qui peut le configurer : **Directeur de centre**, **Administrateur d’agence**.
