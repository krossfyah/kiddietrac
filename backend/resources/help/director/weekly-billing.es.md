# Calendario de facturación

Algunas familias necesitan facturación semanal o quincenal en lugar de mensual. Se configura por familia.

## Configurar el calendario

1. Barra lateral → **Calendario de facturación**.
2. Introduzca el ID de la familia y pulse **Cargar**.
3. Elija la **Frecuencia**: semanal / quincenal / mensual.
4. Para semanal/quincenal, elija un **día de la semana** (0=dom … 6=sáb).
5. Para mensual, elija un **día del mes** (1-31).
6. Pulse **Guardar calendario**.

El sistema calcula la próxima fecha de cobro y se la muestra.

## Cómo sabe el pago automático cuándo cobrar

Cuando la tarea diaria de pago automático se ejecuta a las 03:00 ET, revisa el calendario de cada familia. Si existe un calendario de facturación, cobra en la próxima fecha de cobro. Si no hay calendario, recurre al patrón estándar de fecha de vencimiento de la factura.

## Desactivar

Pulse **Desactivar** para quitar el calendario personalizado. La familia vuelve a la facturación mensual estándar.

## Diferencias

- **Calendario** = CUÁNDO cobrar (cadencia)
- **Cartera predeterminada** = CONTRA QUÉ cobrar (método de pago)
- **Plan de pagos** = UN saldo dividido en varias fechas de vencimiento
