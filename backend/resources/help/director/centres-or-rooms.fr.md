# Centres ou salles

Certaines agences gèrent plusieurs **centres**; d’autres exploitent un seul site comportant plusieurs **salles**. KiddieTrac permet à chaque agence de choisir le mot utilisé partout dans le portail.

## Changer le terme

1. Ouvrez **Modifier l’agence** (depuis la bannière Aperçu de l’agence).
2. Sous **Les installations s’appellent**, choisissez **Centres** ou **Salles**.
3. Le changement est immédiat : la navigation, les titres, les boutons et les rapports adoptent le mot choisi.

Seuls les libellés à l’écran changent; vos données (adresses, noms) ne sont jamais modifiées. Les nouvelles agences peuvent le définir lors de leur première configuration.
