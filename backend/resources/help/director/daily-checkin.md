# Daily check-in

Quick drop-off survey. Parent submits mood + sleep + breakfast status before leaving. Staff see it on the Today screen so they know what to expect.

## Parent submitting

1. Sidebar → **Daily check-in**.
2. Pick child (if more than one).
3. Pick today's mood: 😊 happy / 😴 sleepy / 😩 fussy / 🤒 sick / 😶 quiet.
4. Pick sleep quality: 🌙 great / 🌒 okay / 🌖 restless / 🌘 poor.
5. Tap Yes or No on "Ate breakfast?"
6. Add any medication taken today + any notes for staff.
7. Submit.

## Staff side

- Today screen shows a small badge per child indicating their check-in status.
- Notification fires when each parent submits.
- Tap badge to see full check-in details.

## Different from wellness screening

- **Daily check-in** = social / behavioural ("how is your child today")
- **Wellness screening** = symptom check ("any cough/fever/vomiting")

Both can be submitted independently each morning.

## History

- Last 30 check-ins per child accessible via the **Trends** screen.
- Sleep + mood patterns feed into the AI weekly recap.
