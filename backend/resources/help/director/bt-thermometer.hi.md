# ब्लूटूथ थर्मामीटर

कियोस्क से पेयर किए गए ब्लूटूथ थर्मामीटर से सीधे बच्चे का तापमान पढ़ें।

## सेटअप

1. थर्मामीटर को कियोस्क टैबलेट से पेयर करें (एक बार का सेटअप, ऑपरेटिंग सिस्टम की ब्लूटूथ सेटिंग्स से)।
2. कियोस्क का वेब ब्राउज़र (Chrome 90+, Safari 16.4+) पहली बार तापमान की ज़रूरत पड़ने पर ब्लूटूथ अनुमति माँगता है।

## बच्चे के आने पर

1. अभिभावक / स्टाफ कियोस्क पर बच्चे को चुनता है।
2. **तापमान लें** बटन पर टैप करें।
3. ब्राउज़र Web Bluetooth पेयरिंग डायलॉग दिखाता है।
4. पेयर किया हुआ थर्मामीटर चुनें।
5. रीडिंग स्क्रीन पर दिखती है और कियोस्क रिकॉर्ड अपने आप भर देती है।

## क्या दर्ज होता है

हर रीडिंग `check_events.temperature_c` में इन जानकारियों के साथ सहेजी जाती है:
- तापमान °C में
- विधि: `bluetooth` / `manual` / `scanner`
- जुड़ी हुई चेक-इन घटना की ID (ताकि तापमान आज के आगमन से जुड़ जाए)

## बुखार अलर्ट

यदि रीडिंग **≥ 38°C** हो:
- केंद्र के स्टाफ को **fever_alert** सूचना भेजी जाती है
- कियोस्क "कृपया केंद्र से संपर्क करें" संदेश दिखाता है
- रीडिंग को दैनिक स्वास्थ्य सारांश में चिह्नित किया जाता है

## आवश्यकताएँ

- HTTPS (Web Bluetooth API HTTP पर काम नहीं करता)
- संगत थर्मामीटर (कोई भी उपकरण जो मानक BLE Health Thermometer Service `00001809-0000-1000-8000-00805f9b34fb` उपलब्ध कराता हो)
- Web Bluetooth API वाला आधुनिक ब्राउज़र
- ब्लूटूथ अनुमति दी गई हो

## संगत थर्मामीटर

परीक्षण में काम करने वाले: iHealth, A&D, Beurer FT 90, Withings Thermo। मानक सेवा का उपयोग करने वाले अधिकांश उपभोक्ता BLE थर्मामीटर बिना किसी कस्टम कोड के काम करेंगे।

## विकल्प

यदि ब्लूटूथ उपलब्ध नहीं है, तो उसी कियोस्क विंडो में स्टाफ **विधि = manual** के साथ तापमान हाथ से दर्ज कर सकता है।
