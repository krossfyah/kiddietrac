# Arrivée quotidienne

Un court sondage à l’arrivée. Le parent soumet l’humeur, le sommeil et l’état du déjeuner avant de partir. Le personnel le voit sur l’écran Aujourd’hui pour savoir à quoi s’attendre.

## Soumission par le parent

1. Barre latérale → **Arrivée quotidienne**.
2. Choisissez l’enfant (s’il y en a plus d’un).
3. Choisissez l’humeur du jour : 😊 heureux / 😴 somnolent / 😩 grincheux / 🤒 malade / 😶 calme.
4. Choisissez la qualité du sommeil : 🌙 excellente / 🌒 correcte / 🌖 agitée / 🌘 mauvaise.
5. Touchez Oui ou Non pour « A pris son déjeuner ? »
6. Ajoutez tout médicament pris aujourd’hui et toute note pour le personnel.
7. Soumettez.

## Côté personnel

- L’écran Aujourd’hui affiche un petit insigne par enfant indiquant l’état de son arrivée quotidienne.
- Une notification est envoyée lorsque chaque parent soumet le sondage.
- Touchez l’insigne pour voir tous les détails.

## Différent du dépistage de bien-être

- **Arrivée quotidienne** = social / comportemental (« comment va votre enfant aujourd’hui »)
- **Dépistage de bien-être** = vérification des symptômes (« toux, fièvre, vomissements »)

Les deux peuvent être soumis séparément chaque matin.

## Historique

- Les 30 derniers sondages par enfant sont accessibles depuis l’écran **Tendances**.
- Les tendances de sommeil et d’humeur alimentent le récapitulatif hebdomadaire par IA.
