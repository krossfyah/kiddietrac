# Files shared with families

**Files** (📎 in the sidebar) is where staff and families send each other printables,
homework, notes and signed papers. Directors and agency admins can send files too, and
see every file exchanged with the families they look after.

[[open: #files | Open Files]]

On a phone, **Files** is also in your **Quick access** tiles on the home screen.

## The tabs

- **Received**: files families sent. New ones have a dot, and the tab shows how many are new, for example **Received (3 new)**.
- **Sent**: files you sent yourself.
- **All files**: every file exchanged with the families you can see, in both directions, whoever sent it. The **From → To** column shows who sent it and to which family. Agency admins see the whole agency. Directors see their own centres' families.

> **Tip:** Use **All files** to check what an educator sent a family, or what a family sent back, without asking around.

Educators and home visitors have the same tab, called **All with my families**. It shows
only the families of the children in their care.

## Sending a file

1. Open **Files** and press **📤 Send files**.
2. Drop in or choose up to 10 files, 20 MB each: PDF, pictures, Word, Excel, PowerPoint or text.
3. Add a title and a note if you like.
4. Tick one or more families, then press **Send**.

## Who is told

Whoever a file is for always gets a notification in the app. By default they also get an
email, in **both** directions:

- **Parents** are emailed when a file is sent to them.
- **Staff** who care for the family are emailed when a family sends a file.

The email only says a file is waiting. The file is never attached; it stays in KiddieTrac.

## Turning the emails off (agency admins)

1. Sidebar → **Settings** → **Notifications**.
2. Open the **📎 Shared files** tab.
3. Switch **Email parents about new files** or **Email staff when a family sends a file** on or off.
4. Press **Save**.

With an email switched off, people still see the notification in the app.

??? Can I delete a file an educator sent? | No. Only the person who sent a file can delete it. Deleting removes it for everyone it was sent to.
??? Is this the same as the Files repository? | No. The Files repository is a platform admins' shelf of sales material. Files is for sharing with families.
