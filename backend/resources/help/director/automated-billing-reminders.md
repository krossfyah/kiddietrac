# Automated billing reminders

Under **Billing → Reminders**, agency admins **and** centre directors schedule automatic reminders to families about upcoming and overdue invoices.

## What you can configure

- **Invoice reminders** — remind families a set number of **days before** an invoice is due (e.g. `7, 3, 1`).
- **Overdue reminders** — remind families a set number of **days after** the due date (e.g. `1, 7, 14`).
- **Daily send time** — the hour reminders go out.
- **Email channel** and an optional **custom note** added to every reminder.

Days are counted from each invoice's due date, and each reminder fires once.

## Turning reminders on

Reminders are **off by default**, both per-agency and platform-wide. A banner on the Reminders tab tells you the current status. Once enabled, families begin receiving the reminders you scheduled — so review your day lists and send time first.
