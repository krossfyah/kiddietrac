# Mes feuillets fiscaux (T4, T4A, RL-1)

Quand votre employeur vous paie par la paie KiddieTrac, vos feuillets fiscaux de l'année apparaissent dans **Mes RH › Mes feuillets fiscaux** une fois finalisés (au plus tard fin février). Un avis arrive dans la cloche quand ils sont prêts.

## Ouvrir un feuillet
Touchez un feuillet pour l'ouvrir. Vous pouvez l'enregistrer ou l'imprimer pour votre déclaration de revenus. Il montre les numéros de case de l'ARC (par exemple case 14 revenus d'emploi, case 22 impôt retenu) dans la mise en page de votre employeur, avec votre numéro d'assurance sociale complet. Votre employeur produit aussi le feuillet auprès de l'ARC.

## Les types de feuillets
- **T4** : revenus d'emploi et retenues sur votre paie (RPC ou RRQ, AE, impôt).
- **T4A** : honoraires versés comme travailleur autonome (case 048).
- **Information RL-1** (Québec) : les cases du RL-1. Votre RL-1 officiel vient par Revenu Québec.

## Feuillets modifiés ou annulés
Si votre employeur corrige un feuillet, la nouvelle version est marquée **Modifié** et l'ancienne indique **Remplacé par un feuillet plus récent**. Utilisez celui qui est en vigueur. Un feuillet **Annulé** ne déclare rien.

## Questions
Si un montant semble inexact, communiquez avec le bureau. Seul votre employeur peut corriger un feuillet.
