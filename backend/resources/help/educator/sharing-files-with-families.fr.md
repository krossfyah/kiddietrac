# Partager des fichiers avec les familles

**Fichiers** (📎 dans le menu, et la tuile **📎 Fichiers** de votre écran d’accueil) est l’endroit où vous envoyez documents à imprimer, devoirs et notes aux familles avec lesquelles vous travaillez, et où vous voyez ce qu’elles vous renvoient.

## Envoyer un fichier

1. Ouvrez **Fichiers** et appuyez sur **📤 Envoyer des fichiers** — ou, dans la fiche d’un enfant, appuyez sur **📎 Envoyer un fichier** pour commencer avec cette famille déjà sélectionnée.
2. Déposez des fichiers dans la zone, ou choisissez-les. Vous pouvez en envoyer jusqu’à 10 à la fois, de 20 Mo chacun : PDF, images, Word, Excel, PowerPoint ou texte.
3. Ajoutez un titre et une note si vous le souhaitez.
4. Choisissez les destinataires : cochez une ou plusieurs familles, ou appuyez sur **Toutes les familles de [votre salle]**.
5. Appuyez sur **Envoyer**.

Vous ne pouvez envoyer qu’aux familles des enfants dont vous avez la charge — les mêmes enfants que ceux de votre liste.

## Ce que voient les familles

Les parents reçoivent une notification dans leur appli et, à moins que votre agence l’ait désactivé, un courriel les informant qu’un nouveau fichier les attend. Le fichier lui-même n’est jamais joint au courriel. Ils l’ouvrent dans **Fichiers**, où ils peuvent le consulter ou le télécharger.

## Fichiers que les familles vous envoient

Quand un parent renvoie quelque chose — un devoir terminé, un mot signé — il apparaît sous **Reçu** avec un point jusqu’à ce que quelqu’un l’ouvre. L’onglet indique combien sont nouveaux, par exemple **Reçu (2 nouveaux)**.

Le personnel qui s’occupe de cette famille reçoit une notification dans l’appli et, à moins que votre agence l’ait désactivé, un courriel indiquant qu’un fichier attend.

## Les onglets

- **Reçu** : fichiers envoyés par les familles.
- **Envoyé** : fichiers que vous avez envoyés.
- **Tous avec mes familles** : tous les fichiers échangés avec les familles avec lesquelles vous travaillez, dans les deux sens, peu importe l’expéditeur. La colonne **De → À** indique qui l’a envoyé à qui. Utilisez-la pour voir un fichier qu’un collègue ou votre direction a envoyé à l’une de vos familles.

## Supprimer

Seule la personne qui a envoyé un fichier peut le supprimer (**Supprimer** dans le menu de la ligne). La suppression le retire pour tous ceux à qui il a été envoyé. Chaque téléchargement et chaque suppression sont consignés dans le journal d’audit.
