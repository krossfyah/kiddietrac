# Bienvenue dans Kiddietrac

Kiddietrac est une plateforme moderne de gestion de services de garde conçue pour les centres de l’Ontario. Que vous soyez directeur et gériez les opérations, éducateur auprès des enfants ou parent qui reste en contact, Kiddietrac réunit tout dans une seule application simple.

## Ce que fait Kiddietrac

Pour les **directeurs**, Kiddietrac gère les inscriptions, la facturation, la conformité aux ratios, les certifications du personnel, les rapports d’incident et les exportations de conformité de type CCEYA.

Pour les **éducateurs**, l’affichage sur tablette permet de consigner rapidement les repas, les siestes, les changements de couche, les activités et les observations. Les photos prises sur la tablette sont aussitôt partagées avec les parents. Les ratios quotidiens sont suivis en temps réel.

Pour les **parents**, l’application offre une chronologie en direct de la journée de votre enfant, des résumés quotidiens générés par l’IA, les photos partagées par les éducateurs, un fil de messages avec la salle et vos renseignements de facturation.

## Trois choses à savoir

1. **Votre rôle détermine ce que vous voyez.** Lorsque vous vous connectez, Kiddietrac vous affiche automatiquement la bonne vue.
2. **Les données circulent en temps réel.** Quand un éducateur consigne un repas, il apparaît dans l’application du parent en quelques secondes.
3. **Vos données vous appartiennent.** Les centres sont propriétaires de leurs données et peuvent les exporter en tout temps.

## Par où commencer

- Directeurs → consultez **Configurer votre centre**
- Éducateurs → consultez **Utiliser l’affichage sur tablette**
- Parents → consultez **Votre vue quotidienne**

Si vous ne trouvez pas ce que vous cherchez, cliquez sur le bouton **Demander** dans le coin supérieur de la page d’aide pour obtenir une réponse personnalisée.
