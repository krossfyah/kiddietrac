# Fixing an automatic sign-out time

When nobody signs a child out, or an educator forgets to clock out, KiddieTrac closes the
record automatically at the time your agency has set. The person concerned gets an email with
a link to enter the real time.

- **Parents:** "No sign-out was recorded" — enter the time you actually picked up.
- **Educators:** "No clock-out was recorded" — enter the time you actually left.

## Enter the real time

1. Open the link in the email. No sign-in is needed; the link only works for that one record.
2. Check the **Date**, the centre and the **Automatic time**.
3. Enter the **Actual pick-up time** (or **Actual clock-out time**). It must be after the
   sign-in or clock-in, and no later than the automatic time.
4. Add a **Note** if you like, for example "Grandma picked up".
5. Press **Continue**, check the time, and press **Yes, that’s right**.

The record is updated straight away. For a child, the centre is told; for an educator, the
timesheet changes and the director is told.

> **Tip:** The page uses the language you chose in KiddieTrac.

## When the link does not work

- **Already used:** the time was entered. To change it, contact the centre.
- **Expired:** links last 7 days. Contact the centre to correct the time.
- **Already corrected:** the centre fixed it, so there is nothing left to fill in.

??? Can I use the link twice? | No. Each link works once. If both parents got one, the first answer counts.
??? The time I want is after the automatic time. | The page only accepts a time up to the automatic time. Ask the centre to correct it.
