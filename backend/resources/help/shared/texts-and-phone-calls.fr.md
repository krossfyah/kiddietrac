# Textos et appels téléphoniques — choisir ce que vous recevez

Votre agence peut vous joindre par texto et, pour les avis urgents, par un appel téléphonique
automatisé. Vous choisissez les types que vous souhaitez recevoir.

[[open: #settings?tab=notifications&sub=texts | Ouvrir mes paramètres de textos et d’appels]]

## Où les trouver

- **Tout le monde :** **Paramètres → Notifications**, puis l’onglet **📱 Textos et appels**. (Il se trouvait auparavant dans l’onglet Profil.)
- Les **administrateurs d’agence** peuvent aussi ouvrir **Mon profil** et choisir l’onglet **💬 Textos et appels**.

Les deux affichent les mêmes paramètres : un changement dans l’un apparaît dans l’autre.

## Textos

D’abord, les textos nécessitent votre accord. Si vous n’avez pas encore accepté, la carte l’indique, avec un
bouton **J’accepte de recevoir des textos**. Il montre exactement à quoi vous consentez ; appuyez sur
**Oui** et un texto de confirmation arrive sur votre téléphone.

- [ ] Assurez-vous que votre **numéro de cellulaire** figure dans votre profil.
- [ ] Appuyez sur **J’accepte de recevoir des textos** et confirmez.
- [ ] Désactivez les types de textos que vous ne souhaitez pas.

Ensuite, chaque type de texto a son propre interrupteur :

| Type | De quoi il s’agit |
|---|---|
| Arrivées et départs | Quand votre enfant arrive ou part, et par qui |
| Rappels d’arrivée | Un enfant n’a pas été enregistré à l’arrivée, ou son départ n’a jamais été enregistré |
| Annonces | Les annonces de votre agence, lorsqu’elles sont aussi envoyées par texto |
| Textos groupés | Les messages que le bureau envoie à un groupe, à une salle ou à tout le monde |
| Réponses du personnel | Une réponse à un texto que vous avez envoyé au numéro de l’agence |

Vous ne voyez que les types que votre agence envoie réellement.

## Appels téléphoniques

Les appels d’annonce font sonner votre téléphone et lisent un court message à voix haute — pour les
fermetures, les évacuations, les confinements et autres nouvelles urgentes. Chaque motif d’appel de votre agence a
son propre interrupteur ; vous pourriez donc, par exemple, garder les fermetures et les urgences, mais désactiver les
appels non urgents.

**Ne jamais m’appeler** l’emporte sur tout ce qui précède, **urgences comprises**. Les textos
et les courriels ne sont pas touchés. Si votre agence ne passe pas d’appels pour le moment, la carte
l’indique et conserve vos choix pour quand elle en passera.

![Appels téléphoniques : un interrupteur par motif, et « Ne jamais m’appeler » pour arrêter tous les appels](https://api.kiddietrac.com/help-img/my-texts-and-calls.png)

## Répondre à un texto

- Répondez normalement : votre message parvient au personnel de votre centre, qui peut vous répondre
  par texto.
- Répondez **STOP** pour arrêter tous les textos de votre agence vers ce téléphone. **START** les
  réactive. **HELP** vous indique qui vous écrit et comment le joindre.

## Si vous partagez un téléphone

Si deux comptes utilisent un même numéro — deux parents sur un seul téléphone, par exemple :

- le téléphone reçoit **un seul** exemplaire d’un texto ou d’un appel, et non un par compte ;
- **STOP** ou **Ne jamais m’appeler** depuis ce téléphone s’applique à **tous** les comptes qui l’utilisent
  auprès de votre agence.

## Questions

??? J’ai activé un type de texto, mais je ne le reçois toujours pas. | Votre agence a peut-être désactivé ce type pour tout le monde, ou vous n’avez pas encore accepté de recevoir des textos. Cherchez le bouton J’accepte de recevoir des textos sur la carte.
??? Désactiver les appels arrêtera-t-il les appels d’urgence ? | Désactiver un motif n’arrête que ce motif. « Ne jamais m’appeler » arrête tous les appels, urgences comprises.
??? J’ai répondu STOP par erreur. | Envoyez START au même numéro et les textos reprennent pour tous les comptes de ce téléphone.
