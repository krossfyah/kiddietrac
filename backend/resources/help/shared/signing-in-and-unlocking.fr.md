# Ouvrir l’application, se connecter et déverrouiller

## Ouvrir KiddieTrac

Ouvrez l’application, ou allez sur **app.kiddietrac.com** dans le navigateur de votre téléphone
ou de votre ordinateur. Un court écran de démarrage s’affiche pendant le chargement. Si votre
agence utilise sa propre marque, vous voyez son nom et son logo au lieu de ceux de KiddieTrac.

## Se connecter

1. Entrez votre **Courriel ou nom d’utilisateur** et votre mot de passe.
2. Appuyez sur **Se connecter**.
3. Si l’authentification à deux facteurs est activée, entrez le code à 6 chiffres de votre
   application d’authentification et appuyez sur **Vérifier le code**.

Autres façons de se connecter :

- **Se connecter avec une clé d’accès** — votre visage, votre empreinte ou le NIP de l’appareil
  au lieu d’un mot de passe. Ajoutez-en une sous **Paramètres → Sécurité**.
- **Mot de passe oublié?** — recevez un code à 6 chiffres par courriel, texto ou appel, puis
  choisissez-en un nouveau.

Si un même courriel correspond à plusieurs comptes, on vous demande votre **nom d’utilisateur**.

## Déverrouiller rapidement

Dans l’application, vous pouvez vous passer du mot de passe la fois suivante :

- **Connexion par empreinte / visage** — activez-la sous **Paramètres → Sécurité**.
- **NIP de déverrouillage rapide** — un NIP de 4 à 6 chiffres, aussi sous **Paramètres → Sécurité**.

À l’écran de verrouillage, utilisez **Utiliser plutôt le NIP** ou **Utiliser plutôt le mot de
passe** si le capteur ne vous reconnaît pas. Après trop de NIP erronés, on vous demande de vous
connecter avec votre mot de passe.

## Pourquoi vous avez été déconnecté

La page de connexion vous l’indique :

- **Vous êtes déconnecté.** Vous avez appuyé sur Se déconnecter.
- **Vous avez été déconnecté après une période d’inactivité.** Par sécurité, les sessions se
  terminent quand l’application reste inutilisée.
- **Par sécurité, les sessions sont limitées à 12 heures.**
- **Vous avez été déconnecté dans une autre fenêtre.** Se déconnecter dans un onglet déconnecte
  les autres.
- **Vos accès ont changé.** Votre rôle ou votre agence a changé; reconnectez-vous pour en tenir compte.

??? J’ai oublié mon NIP. | Connectez-vous avec votre mot de passe, puis choisissez un nouveau NIP sous Paramètres → Sécurité.
??? Comment changer la langue? | Sous **Mes paramètres → Langue**. Elle est enregistrée pour votre prochaine connexion, sur tout appareil.
