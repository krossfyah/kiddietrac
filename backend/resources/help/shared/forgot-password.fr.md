# Mot de passe oublié ?

Vous pouvez réinitialiser votre propre mot de passe depuis la page de connexion. KiddieTrac vous envoie un **code à 6 chiffres** par courriel, texto ou appel téléphonique, et vous l’utilisez pour choisir un nouveau mot de passe. Vous n’avez pas besoin de contacter votre centre.

## Obtenir un code

1. Sur la page de connexion, appuyez sur **Oublié ?** à côté de la zone du mot de passe.
2. Dans **Courriel, nom d’utilisateur ou numéro de mobile**, saisissez l’un des trois.
3. Sous **Envoyer mon code par**, choisissez **✉️ Courriel**, **💬 Texto** ou **📞 Appel**.
4. Appuyez sur **Envoyer le code**.

Où va le code :

- **Courriel** : il est envoyé à l’adresse de votre compte. Le courriel contient aussi un lien de réinitialisation sur lequel vous pouvez cliquer au lieu de saisir le code.
- **Texto** : il est envoyé au numéro de mobile de votre compte.
- **Appel** : le numéro de mobile de votre compte sonne, et une voix automatisée lit le code deux fois.

Vous voyez le même message, qu’un compte ait été trouvé ou non : « Si un compte correspond, nous avons envoyé un code à 6 chiffres. » Cela protège votre compte contre les personnes qui essaient de le deviner.

## Saisir le code

1. Saisissez le code à 6 chiffres dans **Code à 6 chiffres**. Dès que les six chiffres sont entrés, il vérifie le code de lui-même. Vous pouvez aussi appuyer sur **Continuer**.
2. Si plus d’un compte utilise ce courriel ou ce numéro de téléphone, choisissez **le compte que vous voulez réinitialiser**.
3. La page **Définir un nouveau mot de passe** s’ouvre. Choisissez votre nouveau mot de passe et enregistrez-le.

Le code est valide **10 minutes**. Après **5 essais incorrects**, il ne fonctionne plus et vous devez en demander un nouveau.

> **Astuce :** Ne partagez jamais votre code. KiddieTrac ne vous le demandera jamais.

## Si le code n’arrive pas

- Attendez 30 secondes, puis appuyez sur **Envoyer un nouveau code**.
- Appuyez sur **Essayer autrement** pour choisir plutôt le courriel, le texto ou un appel.
- Pour le courriel, vérifiez votre dossier de pourriels ou de courrier indésirable.
- Vous avez déjà un code reçu plus tôt ? À la première étape, appuyez sur **J’ai déjà un code**.

Un texto ou un appel ne vous parvient que si votre centre envoie des textos et des appels, et que votre numéro de mobile figure dans votre compte. Sinon, choisissez **Courriel**.

## Plus d’un compte avec un même courriel

Certaines personnes partagent une adresse courriel avec un autre compte, par exemple un parent qui travaille aussi au centre. Ouvrez **Plus d’un compte avec ce courriel ?** et saisissez votre **Nom d’utilisateur** si vous le connaissez. C’est facultatif. Si vous le laissez vide, vous choisissez le compte après avoir saisi le code.

## Se connecter avec une mauvaise connexion

Si votre téléphone ou votre Wi-Fi perd la connexion pendant que vous vous connectez, KiddieTrac réessaie discrètement avant d’afficher une erreur. S’il n’y parvient toujours pas, vous voyez un message clair, par exemple :

- **Vous êtes hors ligne.** Connectez-vous au Wi-Fi ou aux données mobiles, puis réessayez.
- **Nous n’avons pas pu joindre KiddieTrac.** Vérifiez votre connexion Internet, désactivez tout RPV ou économiseur de données, puis réessayez.

Cela signifie que la demande n’a jamais atteint KiddieTrac. Votre mot de passe n’était pas en cause.

??? Le code indique qu’il n’a pas fonctionné ou qu’il a expiré. | Les codes sont valides 10 minutes et permettent 5 essais. Appuyez sur Envoyer un nouveau code et utilisez le plus récent.
??? L’ancien lien de réinitialisation fonctionne-t-il encore ? | Oui. Le courriel contient toujours un lien sur lequel vous pouvez cliquer. Il ne fonctionne qu’une fois et dure 60 minutes.
??? Je vois « Trop d’essais — attendez une minute ». | Attendez une minute, puis réessayez. Cette limite protège votre compte.
