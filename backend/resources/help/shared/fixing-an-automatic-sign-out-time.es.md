# Corregir una hora de salida automática

Cuando nadie registra la salida de un niño, o un educador olvida fichar la salida, KiddieTrac
cierra el registro automáticamente a la hora que haya fijado su agencia. La persona afectada
recibe un correo con un enlace para indicar la hora real.

- **Padres:** «No se registró la salida»: indique la hora real en que recogió al niño.
- **Educadores:** «No se registró el fichaje de salida»: indique la hora real en que se fue.

## Indicar la hora real

1. Abra el enlace del correo. No hace falta iniciar sesión; el enlace solo sirve para ese
   registro.
2. Revise la **Fecha**, el centro y la **Hora automática**.
3. Indique la **Hora real de recogida** (o la **Hora real de salida**). Debe ser posterior a la
   entrada y no más tarde que la hora automática.
4. Añada una **Nota** si quiere, por ejemplo «Lo recogió la abuela».
5. Pulse **Continuar**, revise la hora y pulse **Sí, es correcto**.

El registro se actualiza al instante. Si es un niño, se avisa al centro; si es un educador, se
cambia la hoja de horas y se avisa al director.

> **Consejo:** La página usa el idioma que eligió en KiddieTrac.

## Cuando el enlace no funciona

- **Ya usado:** la hora se registró. Para cambiarla, contacte con el centro.
- **Caducado:** los enlaces duran 7 días. Contacte con el centro para corregir la hora.
- **Ya corregido:** el centro lo solucionó, así que no queda nada por rellenar.

??? ¿Puedo usar el enlace dos veces? | No. Cada enlace funciona una vez. Si ambos padres recibieron uno, cuenta la primera respuesta.
??? La hora que quiero es posterior a la hora automática. | La página solo acepta una hora hasta la hora automática. Pida al centro que la corrija.
