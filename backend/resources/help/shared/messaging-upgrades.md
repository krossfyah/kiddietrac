# Messaging — what's new

The desktop chat now works like a proper messenger.

## A chat window you can move and resize

Open a conversation and it pops out as a floating window in the bottom-right.

- Use **–** to minimise it to a small bar that **stays put while you move around the app**,
  and **✕** to close it. When a new message arrives while it's minimised, the bar flashes.
- **Move it** by dragging its top bar.
- **Resize it** by dragging its right edge, bottom edge or bottom-right corner.
- **The conversation list** on the left can be made wider or narrower by dragging the line
  beside it, or hidden with **«** to leave more room for the conversation.

The window **keeps the size and place you set**. New messages don't resize it, and it opens
the same way next time.

## Normal messages and 🚨 emergencies

Ordinary messages arrive as an ordinary notification: one sound, like any other app.

For a real emergency, use the **🚨** button beside **Send**:

1. Press **🚨** and confirm **Yes, emergency**. The button turns red.
2. Type your message and send it.

Everyone who receives that message has their phone **ring and vibrate continuously until they
open it, for up to 2 minutes**. After that it stays as a missed emergency notification. The
message shows a red **🚨 EMERGENCY** label in the conversation.

- The flag is for **that one message only**. The button switches itself off after you send.
- Press the red **🚨** again before sending to cancel it.
- Parents and staff can both flag a message. It works in the Message Centre, parent
  conversations and conversations with colleagues (on a conversation that has already started).
- Every emergency message is recorded in the audit log, so use it only when it truly is one.

> **Tip:** In a real emergency, still phone the person too. A message can't tell you they've seen it in time.

## Voice notes

Tap the 🎤 microphone to record a voice note; it sends as an inline audio clip that anyone in the thread can **play right in the chat**.

## Paste a screenshot

Copy any image or screenshot and **paste it straight into the message box** (Ctrl/⌘-V) — no need to save the file first.

## Delete messages

- **A message you sent:** open the thread and use the 🗑 on your own message. It leaves a "Message deleted" note.
- **A whole conversation (desktop list):** in the Messages table, the 🗑 at the end of a row removes that conversation.

??? Why don't normal messages ring any more? | Only messages flagged 🚨 ring. Everything else is one ordinary notification, so the ring always means something.
??? Can I flag a message as an emergency after sending it? | No. Turn on 🚨 before you send. If you forgot, send a new message with 🚨 on.
??? My chat window went back to its old size. | Drag it to the size you want once; it is remembered from then on.
