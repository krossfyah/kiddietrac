# कैलकुलेटर

आप जिस स्क्रीन पर हैं, उसके ऊपर एक छोटा कैलकुलेटर खुल जाता है, ताकि आप पोर्टल छोड़े बिना शुल्क, आनुपातिक राशि या रिफ़ंड की गणना कर सकें।

## इसे खोलना

- शीर्ष बार में **🧮** पर क्लिक करें, या
- पोर्टल में कहीं से भी **`Alt + C`** (Windows / Linux) या **`⌥C`** (Mac) दबाएँ, फ़ॉर्म में टाइप करते समय भी।

बंद करने के लिए वही शॉर्टकट, **Esc** या **✕** दबाएँ। इसे हिलाने के लिए इसके शीर्षक को खींचें; अगली बार यह उसी जगह खुलेगा।

## इसका उपयोग

कैलकुलेटर चुना हुआ होने पर कुंजियों पर क्लिक करें या कीबोर्ड से टाइप करें:

| कुंजी | काम |
|---|---|
| `0–9` `.` | संख्याएँ |
| `+` `-` `*` `/` | जोड़, घटाना, गुणा, भाग (`x` भी गुणा करता है) |
| `( )` | कोष्ठक |
| `%` | प्रतिशत: `200 × 15%` = 30, `200 + 15%` = 230, `200 − 15%` = 170 |
| **Enter** या `=` | गणना करें |
| **Backspace** | अंतिम अक्षर हटाएँ |
| **Delete** | साफ़ करें |

उत्तर टाइप करते समय ही दिखता है। आपके पिछले 12 हिसाब डिस्प्ले के नीचे सूचीबद्ध होते हैं; किसी का उत्तर दोबारा उपयोग करने के लिए उस पर क्लिक करें। ब्राउज़र टैब बंद करने पर सूची साफ़ हो जाती है।

## उत्तर को फ़ॉर्म में डालना

जिस फ़ील्ड को भरना है (राशि, दर, घंटे) उसमें क्लिक करें, कैलकुलेटर खोलें, गणना करें और **डालें ↵** दबाएँ। उत्तर सीधे उस फ़ील्ड में चला जाता है। **कॉपी करें** उसे आपके क्लिपबोर्ड पर रखता है।
