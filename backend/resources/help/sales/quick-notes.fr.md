# Notes rapides

Un bloc-notes pour ce que vous devez retenir : écrivez une note en quelques secondes et gardez-la pour vous seul, ou partagez-la avec votre personnel.

## Où la trouver

Ouvrez **Notes** dans votre menu (sous Compte). Vos notes sont pour vous seul.

[[open: #notes | Ouvrir Notes]]

## Écrire une note

1. Ajoutez un **Titre** si vous le souhaitez, puis écrivez la note dans la grande zone en dessous. Sur un ordinateur, appuyez sur **Entrée** pour enregistrer (**Maj+Entrée** commence une nouvelle ligne). Sur un téléphone ou une tablette, Entrée commence une nouvelle ligne et le bouton **Enregistrer** enregistre.
2. La liste n'affiche que le titre de chaque note, sur une ligne. Une note sans titre est listée par sa première ligne. Touchez un titre pour ouvrir la note entière.

## Images

Ajoutez jusqu'à 5 images à une note, par exemple une capture d'écran ou la photo d'un avis :

- Sur un ordinateur, collez une capture d'écran dans la note (**Ctrl+V**, ou **Cmd+V** sur un Mac), glissez-y une image, ou appuyez sur **🖼 Ajouter une image**.
- Sur un téléphone, **🖼 Ajouter une image** ouvre l'appareil photo ou vos photos.
- Vous pouvez ajouter des images en écrivant une nouvelle note ou dans **Modifier la note**. Touchez une image pour la voir en grand ; appuyez sur son **✕** pour la retirer.

Les images sont réduites sur votre appareil et leurs données de lieu sont retirées avant l'envoi. Une image est vue exactement par les personnes qui voient sa note, et elle est supprimée avec elle. Dans la liste, **🖼 3** veut dire que la note a 3 images. Chaque image peut faire jusqu'à 10 Mo.

## Rechercher

Utilisez **Rechercher dans les notes** pour trouver une note par n'importe quel mot de son titre ou de son texte.
