# Notes rapides

Un bloc-notes pour ce que vous devez retenir : écrivez une note en quelques secondes et gardez-la pour vous seul, ou partagez-la avec votre personnel.

## Où la trouver

Ouvrez **Notes** dans votre menu (sous Compte). Vos notes sont pour vous seul.

[[open: #notes | Ouvrir Notes]]

## Écrire une note

1. Écrivez dans la zone et appuyez sur **Entrée** pour enregistrer. **Maj+Entrée** commence une nouvelle ligne.
2. Si la note a plus d'une ligne, la première devient son titre.

## Rechercher

Utilisez **Rechercher dans les notes** pour trouver une note par n'importe quel mot de son titre ou de son texte.
