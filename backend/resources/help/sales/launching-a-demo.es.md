# Hacer una demo en vivo

Nada vende KiddieTrac como verlo funcionar. La pantalla **Iniciar demo** abre la
**Agencia de prueba** en vivo en una pestaña nueva, con sesión iniciada como administrador de demo, para que pueda mostrar
el producto real a un prospecto.

## Cómo funciona

1. Abra **Iniciar demo**.
2. Pulse **🚀 Abrir demo en una pestaña nueva**.
3. Se abre una pestaña nueva con la sesión ya iniciada en la Agencia de prueba; no hace falta iniciar sesión.

Desde ahí puede mostrar asistencia y registro de entrada, facturación y facturas, la aplicación
para padres, mensajería, informes y más. Es el producto completo, con datos de demostración únicamente: **nunca
se muestra información real de ninguna familia**.

## Consejos para una buena demo

- Tenga presente el caso de uso del prospecto y vaya directo a las funciones que lo resuelven
  (p. ej., facturación para una agencia frustrada con las hojas de cálculo).
- La sesión de demo es temporal. Si caduca a mitad de la demo, simplemente inicie una nueva.
- Haga seguimiento después añadiendo una **Propuesta** a su cliente potencial mientras la conversación
  sigue fresca.
