# Proposal terms and defaults

Set up once what every new proposal starts with: how long it is valid, the terms, the
taxes and the sales contact. Anyone on the sales team can change them.

**Where:** sidebar → **Plans & pricing** → the **📄 Proposal terms & defaults** card, below
your plans and discounts.

[[open: #sales-plans | Open Plans & pricing]]

## What you can set

- **Proposals are valid for … days** — a new proposal's **Valid until** date is today plus
  this many days (90 to start with).
- **"Prepared by" contact** — the **Title / team**, **Sales email** and **Sales phone**
  shown under the rep's name on every proposal. Replies to the proposal email go to this
  email, so use the shared sales inbox.
- **Proposal terms (short, under the prices)** — type `{days}` and it is replaced with the
  number of valid days, for example *Prices are valid for {days} days.*
- **Terms & conditions (their own page, before the signatures)** — the full terms. Start a
  line with `##` for a heading or `-` for a bullet.
- **Default taxes** — press **+ Add tax** for each tax most proposals carry (name and rate,
  up to 5).

Press **Save** when you're done.

## How the defaults are used

1. A rep presses **+ New** on a lead's **📄 Proposals** tab.
2. The builder starts with these defaults, plus the rep's own name in **Prepared by**.
3. The rep can change any of it on that one proposal.

Each proposal keeps its own copy. Changing the defaults never changes a proposal that already
exists, so what a prospect signed stays exactly as they saw it.

> **Tip:** Keep the sales email a shared inbox, not one person's address. Prospect replies and signed copies go there.

??? I changed the terms. Why does an old proposal still show the old wording? | Proposals keep the wording they were created with. Edit that proposal to change it, unless it has already been signed.
??? Can one proposal have different terms? | Yes. Change the Proposal terms or Terms & conditions in that proposal's builder.
